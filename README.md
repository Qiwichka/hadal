# Хадаль

Сайт-погружение: прокрутка ведёт с поверхности океана на дно Бездны Челленджера.

- вода, лучи, морской снег и биолюминесценция: фрагментный шейдер на чистом WebGL (`js/sea.js`)
- глубиномер и модель глубины: `js/main.js`
- четыре глубоководных существа на canvas 2D: `js/specimens.js`
- GSAP + ScrollTrigger и Lenis подключаются с CDN, шрифты с Google Fonts

Сборки нет. Запуск:

```bash
python3 -m http.server 5310
```

и открыть http://localhost:5310. Нужен интернет для CDN и шрифтов. Форма внизу страницы только заглушка.
